Campus Club Event RSVP & Attendance Manager - B9IS130 CA1

A full-stack MERN web application designed for university student societies and clubs to manage event creation, streamline member confirmation, and handle attendance tracking. 

The Campus Club Event RSVP & Attendance Manager solves the logistical challenges faced by university societies in organizing and tracking student engagement. The platform offers role-based user management, interactive event browsing, attendance limits, calendar synchronization, and QR-based verification for event checkins.

Target Users & Stakeholders

Student Members: Browse upcoming campus events by club, category, or date. RSVP/register for events with live capacity tracking. Export event dates to personal calendar applications. Export event dates to personal calendar applications.

Club Organizers & Society Execs: Create, update, and moderate society events (Full CRUD). Monitor real-time attendee registrations and export check-in lists. Generate QR codes/verification tokens for seamless event check-ins. 

System Administrators / Campus Security: Global access control, content moderation, and society management.
