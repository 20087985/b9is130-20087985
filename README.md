Campus Lost & Found Portal - B9IS130 CA1

A full-stack web application designed for students and campus staff to report, search, and claim lost or found items across campus, featuring image uploads and an interactive map integration.

Target Users
Students / Staff: Can post lost/found items, view details, upload images, and pin locations.
Campus Security / Admins: Can manage listings, resolve claims, and moderate content.

Tech Stack
Node
MongoDB
